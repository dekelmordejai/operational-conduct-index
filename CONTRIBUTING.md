# Contribuir

Abre un issue describiendo problema, resultado esperado y un caso sintético reproducible. No incluyas datos reales, expedientes, credenciales, capturas internas ni documentos institucionales.

Antes de proponer cambios:

1. Lee metodología y decisiones abiertas.
2. Ejecuta `python -m unittest discover -s tests -v` con `PYTHONPATH=src`.
3. Añade pruebas que verifiquen comportamiento o propiedades nuevas.
4. Explica el impacto sobre compatibilidad y resultados.
5. Cambios de severidad, escala o precedencia requieren nueva versión metodológica.

Las contribuciones originales se ofrecen bajo la licencia MIT del repositorio. No añadir dependencias sin explicar qué necesidad resuelven.
