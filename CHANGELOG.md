# Changelog

## 0.2.0 — 2026-10-16

Dashboard interactivo adaptable: filtros por periodo, empresa y línea, evolución semanal/mensual, composición del índice, comparación de tasas, explorador de eventos con evidencia y exportaciones CSV. Exportación canónica desde Python, 32 pruebas Python y 12 escenarios de paridad navegador/Python. Publicación estática en GitHub Pages condicionada a CI.

## 0.1.0 — 2026-10-16

Primera demo independiente: generación sintética, validación, revisiones e idempotencia, vinculación explícita, contribuciones exclusivas, tasas con exposición, escala fija ilustrativa, informe HTML, auditoría JSON, pruebas y documentación bilingüe de entrada.
