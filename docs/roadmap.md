# Roadmap

## v0.1.0 — Base reproducible

- [x] Motor independiente de presentación y sin credenciales.
- [x] Dataset totalmente sintético, reproducible y con reintentos/solapamientos.
- [x] Validación, revisiones, vinculación explícita y contribuciones exclusivas.
- [x] Tasas agregadas correctamente y referencias fijas versionadas.
- [x] Informe HTML, auditoría JSON, pruebas y configuración de CI.
- [x] Documentar contradicciones, decisiones y limitaciones.

## v0.2.0 — Dashboard interactivo

- [x] Diseño adaptable, navegación móvil y controles de teclado.
- [x] Filtros por fechas, empresa y línea.
- [x] Evolución semanal/mensual del índice y conteos.
- [x] Comparación por empresa o línea, ordenación y detalle.
- [x] Exploración, búsqueda, paginación y evidencia por evento.
- [x] Exportaciones CSV del ámbito y eventos filtrados.
- [x] Paridad de agregación navegador/Python y conservación temporal.
- [x] Configuración de publicación en GitHub Pages después de CI.

## Próximo — Datos e historia

- [ ] Separar entidades y asignaciones temporales.
- [ ] Contratos JSON Schema y validación estructural exhaustiva.
- [ ] Fechas de ingesta/validación, ejecuciones as-of y conciliaciones revisables.
- [ ] Calendario operativo independiente y cuarentena por fila.
- [ ] Implementar SQL/DuckDB, exportación Parquet y benchmarks reproducibles.

## v0.3 — Vinculación evaluada

- [ ] Separar incidente, conducta y alegación.
- [ ] Candidatos aproximados, revisión y fusiones reversibles.
- [ ] Verdad sintética separada y métricas de falsos positivos/negativos.
- [ ] Sensibilidad de precedencia, severidad, referencia y cobertura.

## v0.4 — Producto analítico

- [x] Dashboard interactivo con filtros y explicación por evento.
- [ ] Comparación de escenarios y referencias.
- [ ] API opcional con contratos y pruebas de acceso si la vacante lo justifica.
- [ ] Exposición individual solo con datos de calidad suficiente.

No se prometen integraciones institucionales reales. Cada hito debe cerrar con instrucciones reproducibles, pruebas relevantes y documentación de lo implementado.
